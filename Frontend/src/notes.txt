4 Layers acrchitecture
1)UI --> isme humlog batate hai ki user ko kya dikhe ga + navigate kaise handle karna hai
it contains : -components , -pages
2)HOOKS --> for managing STATES and API Layers
3)STATES -->ye user k data ko manage karne ka kaam karta hai (i.e frontend pe user ka data ko store karne k lea)
it contains : -auth.context.jsx , -ai.context.jsx
4)API --> iska kaam hota hai ki hamara frontend backend se kaise communicate kre ga
it contains : -auth.api.js
iske lea humlog auth folder k andar services folder banai ge uske andar file banai ge auth.api.js
iss file k andar wo code rahega jo frontend ko backend se connect kre ga

frontend ko backend se communicate karne k lea ik package ka zarurat hota hai named as axios
